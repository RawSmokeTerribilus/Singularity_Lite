# --- Singularity Lite Requirements ---
# Every entry here is arch-neutral: pure Python or has aarch64/armhf wheels.
# Nothing pulls a compiler on a normal arm64 install.
#
# EVERY entry is pinned, deliberately. Lite publishes no image — every user
# builds from source, so every install is a fresh dependency resolve and any
# upstream release lands on them immediately. That is not hypothetical: on
# 2026-08-02 an unpinned `cinemagoer` picked up upstream 2026.06.27, which
# deleted the HTTP access system, and every upload crashed with an SQLAlchemy
# error before a single lookup ran.
#
# The versions below are the set running in the maintainer's production image
# (Python 3.11), so they are known-good together. Only direct dependencies are
# pinned; transitive ones are left to the resolver so wheel selection on
# aarch64/armhf stays free.
